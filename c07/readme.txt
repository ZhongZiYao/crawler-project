批量下载网站PDF公告文件的Python脚本工具集。由于发售公告页面结构与其他公告页面不一致，因此提供两个独立的脚本分别处理。

---

## 环境要求

- Python 3.8+
- 依赖库：

```bash
pip install requests beautifulsoup4
```

---

## 脚本说明

### 1. `发售公告抓取.py` - 发售公告专用

**适用页面：** 发售公告栏目（特殊的详情页 + 附件结构）

**特点：**
- 专门处理发售公告的二级页面结构（列表页 → 详情页 → PDF附件）
- 支持单个条目下载和范围下载
- 命令行参数灵活控制

### 2. `main.py` - 通用批量下载

**适用页面：** 其他公告栏目（标准的列表页直链结构）

**特点：**
- 配置文件管理多个下载目标
- 支持不同起始/终止序号的批量下载
- 统一的目录管理

## 使用方式

### 方式一：发售公告下载 (`发售公告抓取.py`)

#### 1. 配置参数

编辑 `发售公告抓取.py` 顶部的用户配置区：

```python
# ╔══════════════════════════════════════════════════════╗
# ║                    用户配置区                        ║
# ╚══════════════════════════════════════════════════════╝

# 目标配置 - 可以配置多个下载目标
TARGETS = [
    # (栏目名, URL, 起始序号, 终止序号)
    # 起始/终止序号从 1 开始计数，终止序号填 None 表示下载到最后
    ("发售公告", "https://www.bqd-wm.com/eportal/ui?pageId=d744d0fa9ee14e6e837c15f191fb0aaa", 1, None),
]

# 基础配置
DOWNLOAD_DIR = "发售公告"  # 下载保存目录
REQUEST_DELAY = 0.5  # 请求间隔（秒）
TIMEOUT = 20  # 请求超时时间（秒）

# ╚══════════════════════════════════════════════════════╝
```

#### 2. 运行

```bash
# 使用配置区设置下载
python 发售公告抓取.py

# 列出所有可下载条目（不下载）
python 发售公告抓取.py --list

# 命令行覆盖下载范围
python 发售公告抓取.py --start 1 --end 10
python 发售公告抓取.py --index 5
```

### 方式二：通用批量下载 (`main.py`)

#### 1. 配置下载目标

编辑 `main.py` 顶部的用户配置区：

```python
# ╔══════════════════════════════════════════════════════╗
# ║                    用户配置区                        ║
# ╚══════════════════════════════════════════════════════╝

TARGETS = [
    # (栏目名, URL, 起始序号, 终止序号)
    # 起始/终止序号从 1 开始计数，终止序号填 None 表示下载到最后
    ("发行公告", "https://www.bqd-wm.com/eportal/ui?pageId=71b994290ccb49cbbc6bdcfda2ca5d4c", 1, None),
    ("到期公告", "https://www.bqd-wm.com/eportal/ui?pageId=99cf7abe92124bfaa635ee3ea5f43787", 1, None),
    ("净值公告", "https://www.bqd-wm.com/eportal/ui?pageId=6f40cd057ed648ceaf2a1f523db30298", 1, None),
    ("定期公告", "https://www.bqd-wm.com/eportal/ui?pageId=c4474374201c475ab1b54121a62f9e23", 1, None),
    ("其他公告", "https://www.bqd-wm.com/eportal/ui?pageId=30b9f1566b9541ce8d14e9456d6f505d", 1, None),
]

DOWNLOAD_DIR  = "downloaded_files_bqd"
REQUEST_DELAY = 0.5
TIMEOUT       = 30

# ╚══════════════════════════════════════════════════════╝
```

| 字段 | 类型 | 说明 |
|------|------|------|
| 栏目名 | `str` | 保存时的文件夹名，可自定义 |
| URL | `str` | 对应栏目的列表页地址 |
| 起始序号 | `int` | 从第几条开始，从 `1` 开始计数 |
| 终止序号 | `int\|None` | 下载到第几条，`None` 表示下载到最后一条 |

> 序号按列表页从上到下的顺序排列，跨页连续计数。

**示例配置：**

```python
TARGETS = [
    # 下载发行公告全部
    ("发行公告", "https://www.bqd-wm.com/eportal/ui?pageId=71b994290ccb49cbbc6bdcfda2ca5d4c", 1, None),

    # 只下载到期公告前50条
    ("到期公告", "https://www.bqd-wm.com/eportal/ui?pageId=99cf7abe92124bfaa635ee3ea5f43787", 1, 50),

    # 下载净值公告第11-30条
    ("净值公告", "https://www.bqd-wm.com/eportal/ui?pageId=6f40cd057ed648ceaf2a1f523db30298", 11, 30),

    # 下载定期公告第101-200条
    ("定期公告", "https://www.bqd-wm.com/eportal/ui?pageId=c4474374201c475ab1b54121a62f9e23", 101, 200),
]
```

#### 2. 运行

```bash
# 使用配置文件下载
python main.py

# 列出所有目标的可下载条目（不下载）
python main.py --list

# 命令行临时覆盖所有目标的下载范围
python main.py --start 1 --end 20
python main.py --index 5
```

### 3. 输出结构

#### main.py 输出：
```
downloaded_files_bqd/

│   ├── 2026-02-26_发行公告标题.pdf
│   └── ...

│   └── ...
├── 定期公告/
│   └── ...

```

文件命名格式：`{日期}_{标题}.{扩展名}`

## 命令行参数（可选）

两个脚本都支持命令行参数来临时覆盖配置文件中的设置：

### 发售公告抓取.py

| 参数 | 类型 | 说明 |
|------|------|------|
| `--list` | - | 仅列出所有可下载条目，不执行下载 |
| `--start N` | `int` | 覆盖起始下载序号（从1开始） |
| `--end N` | `int` | 覆盖终止下载序号（包含该序号） |
| `--index N` | `int` | 下载指定序号的单个条目 |
| `--timeout N` | `int` | 覆盖请求超时时间（秒） |

### main.py

| 参数 | 类型 | 说明 |
|------|------|------|
| `--list` | - | 列出所有目标的可下载条目，不执行下载 |
| `--start N` | `int` | 覆盖配置中所有目标的起始序号 |
| `--end N` | `int` | 覆盖配置中所有目标的终止序号 |
| `--index N` | `int` | 所有目标仅下载指定序号条目 |

## 实现原理

### 架构差异说明

  个脚本采用不同的技术路径，对应不同的页面结构：

#### 发售公告抓取.py（发售公告专用）

```
发售公告特殊结构：
─────────────────────────────────────────────────────
列表页HTML → 提取详情页链接
  → 遍历每个详情页 → 提取PDF附件链接
  → 直接下载PDF文件
  → 文件名：{标题}__{原始文件名}.pdf
```

**技术特点：**
- 二级页面结构：列表页 → 详情页 → PDF附件
- 每个详情页可能包含多个PDF附件
- 需要解析HTML提取PDF链接

#### main.py（通用批量下载）

```
标准公告结构：
─────────────────────────────────────────────────────
列表页HTML → 直接提取PDF文件链接
  → 使用PDF查看器路径（viewer.html?file=）
  → 直接下载PDF文件
  → 文件名：{清理后的标题}.pdf
```

**技术特点：**
- 单级页面结构：列表页 → PDF文件
- PDF链接内嵌在查看器URL中
- 批量处理多个栏目

### 页面结构识别

#### 发售公告页面特征：
```html
<!-- 列表页 -->
<a href="/qylc/xxpl/fsgg/202401/1234567/index.html">详情</a>

<!-- 详情页 -->
<a href="/qylc/xxpl/fsgg/202401/1234567/attachment.pdf">下载附件</a>
```

#### 其他公告页面特征：
```html
<!-- 列表页 -->
<a href="/eportal/uiFramework/js/pdfjs/web/viewer.html?file=/path/to/file.pdf">标题</a>
```

### 文件命名规则

| 脚本 | 命名格式 | 示例 |
|------|----------|------|
| `发售公告抓取.py` | `{标题}__{原始文件名}.ext` | `2024年第一期发售公告__20240101.pdf` |
| `main.py` | `{清理后的标题}.ext` | `2024年第一期发行公告.pdf` |

## 选择指南

### 使用 `发售公告抓取.py` 当：
- 需要下载**发售公告**
- 需要精确控制单个条目下载
- 页面结构为：列表页 → 详情页 → 附件

### 使用 `main.py` 当：
- 需要下载**其他类型公告**（发行/到期/净值/定期等）
- 需要配置多个下载目标
- 页面结构为：列表页 → 直链PDF

## 注意事项

- **断点续传**：已下载的文件自动跳过，支持断点续跑
- **请求频率**：默认设置了请求间隔（0.5秒），避免对服务器造成过大压力
- **错误处理**：网络异常自动跳过，详细错误日志便于排查
- **文件权限**：确保有足够的磁盘空间和写入权限
- **编码处理**：自动检测并处理中文编码问题

### 常见问题

**Q: 如何判断使用哪个脚本？**
A: 查看目标页面URL，包含 `/fsgg/` 的发售公告使用 `发售公告抓取.py`，其他使用 `main.py`

**Q: 下载速度慢怎么办？**
A: 可以适当减少配置区中的 `REQUEST_DELAY` 参数，但不建议低于0.3秒

**Q: 部分文件下载失败？**
A: 检查网络连接，或者文件可能已被删除/移动，脚本会显示具体错误信息

**Q: 如何添加新的下载目标到main.py？**
A: 在配置区的 `TARGETS` 列表中添加新的元组：`("栏目名", "URL", 起始序号, 终止序号)`
